ONNX Models License Information
=====================================

This directory contains the following pre-trained ONNX models:

1. SCRFD Face Detector (scrfd_10g_bnkps.onnx)
   - Source: InsightFace (https://github.com/deepinsight/insightface/tree/master/detection/scrfd)
   - License: Apache License 2.0
   - Repository: https://github.com/deepinsight/insightface
   - Downloaded from: https://huggingface.co/LPDoctor/insightface
   - Model description: Efficient face detection with 5 keypoints (eyes, nose, mouth)
   - Input: [1, 3, H, W] RGB image (dynamic resolution)
   - Output: Face bounding boxes, scores, and 5 facial landmarks

2. ArcFace Face Recognition (arcface_w600k_r50.onnx)
   - Source: InsightFace (https://github.com/deepinsight/insightface/tree/master/recognition/arcface_torch)
   - License: Apache License 2.0
   - Repository: https://github.com/yakhyo/face-reidentification
   - Downloaded from: https://github.com/yakhyo/face-reidentification/releases
   - Model description: Face embedding/recognition model (ResNet-50, trained on MS1MV2)
   - Input: [1, 3, 112, 112] RGB face crop
   - Output: [1, 512] embedding vector
